# Tesseract OCR Guide

Transform scanned PDF documents into searchable text PDFs using Tesseract OCR.

---

## 👁️ Features

- Searchable PDF generation with transparent text layer.
- Automatic page deskewing (`deskew=true`).
- Support for 100+ Tesseract language packs (`eng`, `fra`, `deu`, `spa`, `ta`, `hi`, etc.).

---

## 🛠️ Usage Instructions

1. Select **Tools** -> **OCR Processing**.
2. Upload scanned PDF.
3. Select primary document languages (e.g. `eng,fra`).
4. Click **Run OCR** to download searchable PDF.
