# Frequently Asked Questions (FAQ)

### Q: Is PaperForge free and open-source?
**A:** Yes, PaperForge is 100% open-source software licensed under the MIT License.

### Q: Are there any artificial limits on user accounts or file processing?
**A:** No. PaperForge features an unlimited-user architecture with zero application-level user caps. File size and job limits are configurable via environment variables (`PAPERFORGE_MAX_FILE_SIZE`).

### Q: Does PaperForge work offline?
**A:** Yes! The PaperForge Desktop application (Tauri + Rust) and Docker container stack operate completely offline.

### Q: How do I change the interface language?
**A:** Click the language selector dropdown in the top header navbar to switch between 10 supported languages (including Arabic RTL layout).
