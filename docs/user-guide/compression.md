# PDF Compression Guide

Reduce PDF file size for email attachments and web publishing using `qpdf` stream optimization.

---

## 🗜️ Compression Presets

| Preset | Stream Compression | Linearize | Best For |
| :--- | :--- | :--- | :--- |
| **LOW** | Level 3 | No | Preserving high-res graphics |
| **BALANCED** | Level 6 | Yes | Standard email & web distribution |
| **HIGH** | Level 9 + Flate | Yes | Maximum file size reduction |

---

## 🛠️ Usage Instructions

1. Select **Tools** -> **Compress PDF**.
2. Upload PDF file.
3. Choose compression preset (`BALANCED` recommended).
4. Download compressed PDF and review compression metrics (% saved).
