# Interactive PDF Editor Guide

The PaperForge in-browser PDF Editor allows viewing, drawing, annotating, and editing PDF files locally without uploading file contents to remote servers.

---

## ✏️ Editor Capabilities

- **Page Rendering**: High-fidelity PDF page rendering powered by `pdfjs-dist`.
- **Annotations**: Freehand drawing, vector text annotations, highlights, and shape drawing.
- **Client-Side Caching**: Fast page rendering and thumbnail generation backed by IndexedDB (`idb`).
- **Export & Flattening**: Flatten annotations directly into new PDF files via `pdf-lib`.

---

## 🛠️ Usage Instructions

1. Navigate to **PDF Editor** in the sidebar.
2. Drag and drop a PDF file into the editor viewport.
3. Use the toolbar to draw, annotate, or highlight text.
4. Click **Export PDF** to save changes.
